# Briyany live homepage

Built with React + Vite. The page uses a text-based BRIYANII wordmark, a horizontal camel animation, and a simple menu.

Run locally:
```bash
npm install
npm run dev
```
Open the localhost URL shown by Vite.

To create a single-file preview that customers can open in a browser without installing npm or other tools, run:
```bash
npm run build:preview
```
Send them `BRIYANII-preview.html`. It includes the page styles, scripts, and camel image, and can be opened directly in a modern browser.
